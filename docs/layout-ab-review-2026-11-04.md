# ONE DAY — เปรียบเทียบผัง A/B วันที่ 4 พฤศจิกายน 2569

สถานะ: แนวคิดเพื่อเทียบทางเลือก ยังไม่ใช่ผังมาตราส่วนหรือแบบก่อสร้าง ไม่มีข้อมูลวัดหน้างานใน repository นี้ จึงยังไม่ยืนยันจำนวนโต๊ะหรือความปลอดภัยของทางรถ

## ตำแหน่งหลักที่ต้องรักษา

มองจากถนนเข้าร้าน: ซุ้มขาวหลังคาชมพูอยู่ด้านหน้า บาร์อยู่ด้านขวา ตรอ. อยู่ด้านซ้าย โครงด้านหลังแยกเป็นพื้นที่พักอาศัย ทางสัญจรรถ ตรอ. และทางเข้าที่พักต้องไม่กลายเป็นพื้นที่วางโต๊ะหรือคิวรับสินค้า

| จุดเปรียบเทียบ | A: 4 โต๊ะ | B: 5 โต๊ะ |
| --- | --- | --- |
| การจัดพื้นที่ | เริ่มจาก 4 โต๊ะพร้อมเก้าอี้ในตำแหน่งใช้งานจริง | เพิ่มโต๊ะที่ 5 เฉพาะพื้นที่ที่เหลือหลังกันทางเดินและทางรถแล้ว |
| ทางพนักงาน | ตรวจเส้นทางครัว/บาร์ → จุดรับ → ทุกโต๊ะ → เก็บจาน | ตรวจเส้นทางเดิมซ้ำพร้อมลูกค้านั่งครบและเก้าอี้เลื่อนออก |
| คิวซื้อกลับ | กันพื้นที่คิวและรอรับแยกจากทางเสิร์ฟ | ต้องรักษาพื้นที่คิวเท่า A ห้ามใช้พื้นที่คิวเป็นโต๊ะเพิ่ม |
| ทางรถ ตรอ. | บันทึกขอบเขตทางเข้าออกและวงเลี้ยวตามรถจริง | ห้ามโต๊ะ เก้าอี้ หรือคิวล้ำขอบเขตเดียวกัน |
| พื้นที่พักอาศัย | รักษาทางเข้าออกแยก | ไม่ใช้ทางเข้าที่พักรองรับโต๊ะที่ 5 |
| เกณฑ์เลือก | ใช้เป็นตัวเลือกเริ่มตรวจ | เลือกได้เมื่อผ่านข้อจำกัดทุกข้อเท่ากับ A และวัดได้จริง |

## ข้อมูลที่ต้องเติมก่อนวาดผังมาตราส่วน

- ขนาดที่ดินและพื้นที่ใช้งาน; ตำแหน่งเสา ผนัง ประตู ระดับพื้น และแนวถนน
- ขนาดซุ้ม บาร์ ครัว ตู้เย็น จุดรับสินค้า และระยะเปิดประตู/ตู้
- ขนาดโต๊ะและเก้าอี้ รวมพื้นที่เมื่อนั่งและเลื่อนเก้าอี้
- แนวทางรถเข้าออก ตรอ. ชนิดรถและพื้นที่วงเลี้ยวจริง
- ข้อกำหนดทางเดิน การเข้าถึง ทางหนีไฟ และทางเข้าออกที่พักที่ผู้รับผิดชอบหน้างานยืนยัน

ขั้นตอนตรวจ: วัดและตีเส้น A → ทดลองนั่ง/เดินเสิร์ฟ/เก็บจาน/รอรับ → ตรวจทางรถ → บันทึกระยะคอขวด → ทดลอง B ด้วยเกณฑ์เดิม → เลือกจำนวนโต๊ะจากผลตรวจ ไม่เพิ่มโต๊ะในเกมแทนการยืนยันหน้างาน

เกมยังคง T1–T3 ตามโค้ดปัจจุบัน; การศึกษา A/B นี้เป็นงานร้านจริงแยกจากจำนวนโต๊ะใน simulation
